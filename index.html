Help & Known Issues

Browser Requirements

  • Chrome or Edge required — Web Bluetooth is not supported in Firefox or Safari.
  • Must be on localhost or HTTPS for Web Bluetooth to work.
  • For LAN access, enable chrome://flags/#unsafely-treat-insecure-origin-as-secure and add your LAN URL (e.g. http://10.x.x.x:8081).

BLE / Connection

  • Only 1 client at a time — ESP32 supports a single BLE connection. Disconnect other apps/tabs first.
  • Tab switching may disconnect — Keep this tab active during experiments. The orange warning banner will appear if you switch away.
  • "Scan Any" shows no data? — After scanning, click Browse Services, then Subscribe on a notify characteristic.
  • Device not appearing in scan? — Make sure the ESP32 is powered on and not connected to another device.
  • Auto-reconnect tries 5 times with exponential backoff when a device disconnects unexpectedly.

Recording & Data

  • Data is only saved when recording — Click ⏺ Record and name your session before collecting data you want to keep.
  • Export before leaving — Data is stored in the browser's IndexedDB; clearing browser data will erase experiments.
  • Use 📂 History to view, export, or delete past experiments.
  • CSV export from the toolbar exports in-memory data only. For full data, use History → View → CSV.

Annotations

  • Annotations mark the current time on the chart with a yellow dashed line.
  • They are saved with the session and included in JSON exports.
  • Add annotations to mark key experimental events (e.g. "added weight", "changed resistance").

Quick Start

  1. Click + Connect Device → pick a preset like "SensorLab ESP32".
  2. Click ⏺ Record, name your experiment.
  3. Data streams live to the chart.
  4. Use 📌 Annotate to mark key moments.
  5. Click ⏹ Stop when done, then export CSV/JSON.
